# Update 35 — Service Inventory and column choices

- Consistent 44 px buttons, aligned filter labels, wrapped table headings and labelled responsive stock-count cards. Mobile workspace headers scroll with the page rather than covering forms. Column handling no longer adds redundant colspan attributes that hid mobile field labels and distorted function row counts.
- Stock and service-job details expand as a full-width section immediately below the selected row. No detail popup or nested detail table.
- Stock Check counts visible custody together by product/lot/expiry, without choosing an individual stock holder. Select all and Deselect all are available. Approvers count all custody; ordinary engineers count their authorized custody.
- Matching counts complete without stock movement. Differences require justification and independent approval. The disclosed allocation distributes the counted total proportionally over existing custody, preserves whole-unit quantities, and records each holder adjustment. A changed balance invalidates the pending count until it is recounted. Historical individual-holder checks remain available.
- Approvals tab collects issue/return requests and stock-count decisions. System Admin has inventory approval permission. A requester cannot approve their own request, including an administrator; request/return recipients also cannot approve their transfer. The page now explains this instead of silently omitting the reason. Another authorized account must decide. Cancellation remains available.
- Column choices include all defined customer/supplier/product/warehouse master fields, document source header fields, authorized scalar CRM fields and display names, scalar fields for Portal rows with a record reference, service schema fields and relationship names, budgeting line attributes, and additional inventory/track-record fields. Sensitive credentials, signature data, binary files, nested payloads and removed obsolete form fields are excluded. Calculated report tables expose their report columns; unrelated raw record fields are not injected into aggregate results.
- Extra columns start hidden to retain a compact view. Use Columns to show, rename and order them, then save per account. Expanded column sets may require re-saving the layout for that register.

Validation: 15 inventory/workflow tests, 4 table-layout API tests, 6 role-catalog tests; browser checks at 320, 390, 768, 1024 and 1440 px for inline details, consolidated counts, bulk selection and approvals. Staff Portal route audit: 126 current page/viewport combinations without document overflow or script errors. Additional checks verify master/source-document/CRM column choices. QA transactions use a separate database and are not included in the delivered database.

This package updates the application source and bundled test database. Deploy it to update the Railway site. Existing production stock records are preserved; no test stock should be seeded automatically on deployment.
