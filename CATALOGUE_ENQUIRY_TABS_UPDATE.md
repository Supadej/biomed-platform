# Website Product Catalogue — Enquiry-first tabs

Catalogue Management now opens on the **Received Enquiries** tab by default. **Products & Listings** contains individual record search, editing, and pagination. **Bulk Publishing & Import** contains Biomed IS synchronization, CSV import, and bulk publication controls.

The three sections share their existing APIs and permissions. Nothing has been changed in the enquiry submission or automatic Sales Plan Unassigned lead creation logic.

When the catalogue is opened from Staff Portal, it continues to use the embedded view and the existing portal header/sidebar.

Validation: inline JavaScript syntax and HTML tab structure were checked. Live Railway authentication and end-to-end browser behavior have not been verified.
